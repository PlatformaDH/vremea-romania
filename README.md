# Vremea în România

Aplicație web care arată vremea actuală, următoarele ore și prognoza pe 7 zile. Alegi județul și localitatea; datele vin de la [Open-Meteo](https://open-meteo.com/).

## Pornire locală

Deschide `index.html` în browser sau pornește un server local în acest folder:

```bash
python -m http.server 8765
```

Apoi accesează [http://127.0.0.1:8765/](http://127.0.0.1:8765/).
